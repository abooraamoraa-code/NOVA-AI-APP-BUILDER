# 🚀 NOVA AI App Builder

> منصة متقدمة لإنشاء التطبيقات والبرمجيات من وصف نصي باستخدام الذكاء الاصطناعي.

## 🌐 عن المشروع

**NOVA AI App Builder** هي منصة تهدف إلى تحويل فكرة المستخدم المكتوبة باللغة الطبيعية إلى مشروع برمجي قابل للتنزيل والتطوير.

يتم بناء المنصة باستخدام بنية Backend وDatabase خارجية، مع فصل واضح بين واجهة المستخدم والخدمات الخلفية والذكاء الاصطناعي ونظام الحسابات والمدفوعات والإدارة.

## 🧠 الذكاء الاصطناعي

تعتمد المنصة على واجهات برمجة تطبيقات خارجية للذكاء الاصطناعي.

سيتم وضع مفاتيح API داخل بيئة الخادم فقط، ولن يتم إرسال المفاتيح إلى المتصفح أو تضمينها داخل ملفات الواجهة.

سيتم بناء طبقة مستقلة للتعامل مع:

* إرسال الطلبات
* استقبال النتائج
* معالجة الأخطاء
* إعادة المحاولة عند الحاجة
* إدارة استخدام المفاتيح
* مراقبة استهلاك الخدمة

جميع العمليات الحساسة يتم التحقق منها على الخادم.

---

## 💎 نظام الرصيد

سيحتوي النظام على رصيد مجاني ورصيد مدفوع.

يتم تسجيل عمليات الرصيد في قاعدة البيانات، ولا تعتمد قيمة الرصيد على بيانات موجودة في المتصفح فقط.

مثال:

```text
رصيد المستخدم
     │
     ├── رصيد مجاني
     │
     └── رصيد مدفوع
            │
            ▼
       استخدام الخدمة
            │
            ▼
        خصم الرصيد
```

---

## 🎟️ نظام الرموز

يمكن للإدارة إنشاء رموز ترقية من لوحة الإدارة.

كل رمز يمكن أن يحتوي على:

* قيمة أو خطة
* عدد نقاط
* حالة الرمز
* تاريخ الإنشاء
* تاريخ الانتهاء عند الحاجة
* المستخدم الذي استخدم الرمز
* تاريخ الاستخدام

ولا يتم اعتبار الرمز صالحًا اعتمادًا على واجهة المستخدم فقط؛ بل يتم التحقق منه على الخادم.

---

## 💳 نظام الدفع

سيتم بناء صفحة دفع تعرض الخطة المختارة وتعليمات الدفع ووسيلة الدفع المتاحة.

سيتم فصل:

```text
اختيار الخطة
      ↓
إنشاء عملية دفع
      ↓
تأكيد الدفع
      ↓
تحديث الرصيد
```

ولا تعتبر العملية مدفوعة إلا بعد تحقق النظام من حالة الدفع وفق آلية الدفع المستخدمة.

---
